# SmartLogistics: Delivery Time Prediction & Analysis

A data science project analyzing multi-partner delivery performance and forecasting delivery times across India.

## Workflow
1. **Data Cleaning:** Parsed timestamp hour formats, handled missing values, and created domain metrics (`cost_per_km`).
2. **Exploratory Data Analysis:** Evaluated weather impacts and carrier performance with Seaborn and Matplotlib.
3. **Machine Learning:** Built a Random Forest regression pipeline predicting shipment duration ($R^2 > 0.85$).
